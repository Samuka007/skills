用你本机已安装的 agent-session-batch-export skill，把我历史 session 里「非编程」主题的对话导出成一个可以交付给别人的语料包。

要求：

1. 不要人工复核环节。直接全自动导出 —— 这个 skill 有明确的 no-review 出口，用它，并且让 manifest 如实记录「这批没有经过人工复核」。
2. 不要设对话轮数下限。哪怕只有一轮、一问一答就结束的会话，也必须进入候选，不要因为「太短」被过滤掉。
3. 主题范围是非编程。翻译、写作、语言学习、角色扮演、日常问答这类都算；写代码、调试、运维、配置服务器不算。
4. 导出完成后，把结果打成一个压缩包。
5. 最后向我报告三件事：候选了多少条会话、实际导出了多少条、以及每一条导出会话的**第一句用户消息原文**。

环境说明：skill 的脚本是 bash 写的，这台机器是 Windows。用 Git Bash 跑，或者用 skill 自带的 .ps1 包装器跑，你自己判断哪个稳。

先读 skill 的 SKILL.md 再动手，按它写的接口来，不要自己另写一套导出逻辑。
